Hello, I'm Yann. I'm an Electrical and Computer Engineering student focusing on Machine Learning and AI. Below are some of my key projects and research highlights.

Multimodal Gaussian Process Fusion (Spring 2026)

  • Ran a 9,703-configuration ablation of multimodal GP fusion (9 embedders × 3 GP scaling methods × 5 ensemble modes); a data-pipeline fix raised best test R² from 0.629 to 0.662.
  • Built a spectrally-normalized MLP over Gemini text embeddings to extract a 128-d GP input, reaching test R² 0.6685 / NLPD 0.57.

Research with K. Polyzos, Schmidt AI in Science (UCSD); manuscript in preparation

Hybrid RAG over Technical Docs (Spring 2026)

  • Engineered a hybrid RAG pipeline — hierarchical chunking, bge-m3 dense + BM25 sparse fused by reciprocal-rank fusion, then a cross-encoder reranker — reaching F1@5 0.853 / Precision@5 0.889.
  • Designed a HyDE query stage with parent-chunk expansion and a 1,700-token context packer.

Modular Flashcard Maker (Spring 2025)

  • Built a locally accessible browser interface combining frontend and backend for flashcard generation.
  • Runs entirely on your machine using Ollama to interface with downloaded language models.
  • Supports integration with local models via Ollama, including llama3.1:latest.
  • Modular architecture for swapping models and customizing few-shot prompts.
  • Free and offline: once set up, it's perfect for quick use when you're in a bind—no internet required.
